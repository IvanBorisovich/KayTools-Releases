# Продукты

| ID | Название | Исполняемый файл | Канал |
|---|---|---|---|
| `search` | KaySearch | KaySearch.exe | stable после приёмки |
| `backup` | KayBackUp | KayBackupManager.exe | stable после приёмки |
| `tester` | KayTester | KayStorageTester.exe | stable после приёмки |

KayTools управляет установкой этих трёх продуктов. Версии независимы: исправление одного приложения не требует переустановки остальных.
