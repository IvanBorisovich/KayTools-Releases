# Подписанный каталог

`stable.json` — конверт с Base64-полями `payload` и `signature`.
Клиент проверяет подпись RSA-PSS/SHA256 встроенным открытым ключом до использования каталога.

Подписанные данные содержат `schema`, возрастающий `sequence`, время `publishedUtc` и список `apps`.
Запись приложения содержит ID, версию `X.Y.Z`, ссылку на пакет Releases, размер, SHA256, описание изменений и перечень программных файлов с размерами и SHA256.

**В этом репозитории не должно быть приватных ключей или токенов публикации.**
Не создавайте заглушку `stable.json` с вымышленной подписью. Отсутствие каталога до первого релиза — штатное состояние.
