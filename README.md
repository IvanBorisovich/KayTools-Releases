## Установка KayTools 2.0.4

Скачайте [**KayTools-2.0.4-win-x64-Setup.exe**](https://github.com/IvanBorisovich/KayTools-Releases/releases/download/suite-2.0.4-run39315562393-attempt1/KayTools-2.0.4-win-x64-Setup.exe)
и запустите в Windows x64. Установщик включает .NET; Visual Studio не требуется.

**После Preview/RC один раз установите этот новый setup:**
стабильный выпуск использует новый открытый ключ проверки обновлений.
Если уже установлен KayTools 2.0.1 или новее, используйте раздел **«Обновления»** — повторная установка setup не нужна.
Дальнейшие обновления и установка приложений доступны внутри KayTools.

[Описание стабильного выпуска и все файлы](https://github.com/IvanBorisovich/KayTools-Releases/releases/tag/suite-2.0.4-run39315562393-attempt1).
Автоматические проверки сборки, установки, безопасности, упаковки и интерфейса
пройдены в Windows CI. Ручная проверка расширений во всех пяти браузерах ещё
предстоит. Установщик пока без Authenticode-сертификата; подпись каталога обновлений
проверяется отдельно встроенным в KayTools открытым ключом.

В составе выпуска: **Kay Video Downloader 1.1.0**. Добавлены плейлисты: выбор роликов галочками, миниатюры, лучшее качество или предел вплоть до 2160p (4К), исходный звук / MP3, отдельная папка с порядковыми номерами файлов и общий прогресс. Ошибка отдельного ролика не останавливает группу. В окне приложения отображаются первые 500 записей; для больших плейлистов показано уведомление. Расширения продолжают работать с отдельным видео без переустановки.

## Приложения

| Приложение | Для чего | Права администратора |
| --- | --- | --- |
| **KaySearch** | Поиск по документам и содержимому файлов | Обычно не требуются |
| **KayBackUp** | Резервное копирование файлов | Обычно не требуются; доступ к папкам определяется Windows |
| **KayTester** | Проверка ёмкости и скорости USB-накопителей | Требуются для работы с дисками |
| **Kay Video Downloader** | Скачивание видео или звука по ссылке, выбор качества и папки | Не требуются |

> Проверки KayTester могут уничтожать данные выбранного накопителя. Перед запуском сохраните важные файлы.

В KayTools выберите приложение и нажмите **«Установить»**. Оболочка скачает пакет,
проверит подпись каталога и содержимое ZIP, установит приложение и покажет
**«Запустить»**. После «Обновления → Приложения» кнопки установки остаются доступны.
Ранее проверенные установленные приложения доступны и без сети.

На рабочем столе достаточно одного ярлыка KayTools. После запуска приложения
оболочка сворачивается в область уведомлений. Kay Video Downloader также
поддерживает работу в трее. Браузерные пакеты для Chromium (Chrome, Edge, Opera,
Яндекс) и Firefox приложены к выпуску; пока установка через режим разработчика.
Для постоянной установки Firefox требуется подпись Mozilla.

## Структура хранилища

| Раздел | Содержимое |
| --- | --- |
| `catalog/stable.json` | Подписанный стабильный каталог: оболочка и четыре приложения |
| `catalog/preview.json` | Исторический Preview-каталог; прежний ключ сохранён для старых RC |
| `apps/` | Справочная информация о продуктах |
| `docs/` | Установка, безопасность и правила выпуска |
| **Releases** | Готовые ZIP-пакеты и установщик; не исходный код |

Закрытый ключ подписи хранится в GitHub Actions Secrets приватного репозитория
KayTools, в исходники и пакеты не входит. Исходный код приложений не публикуется
в этом репозитории. Публичная доступность файлов не означает предоставления
лицензии на исходный код или прав на торговые обозначения.
