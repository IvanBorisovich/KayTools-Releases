## Статус

**KayTools 2.0 RC1 — публичный Preview для проверки в Windows 11 x64.**
Это предварительный выпуск, не стабильный релиз. Автоматические сборки прошли; ручная приёмка в Windows/Parallels ещё предстоит.

## Приложения

| Приложение | Для чего | Права администратора |
|---|---|---|
| **KaySearch** | Поиск по документам и содержимому файлов | Обычно не требуются |
| **KayBackUp** | Резервное копирование файлов | Обычно не требуются; доступ к папкам определяется Windows |
| **KayTester** | Проверка ёмкости и скорости USB-накопителей | **Требуются для работы с дисками** |

> Проверки KayTester могут уничтожать данные выбранного накопителя. Перед запуском сохраните важные файлы.

## Установка

Скачайте [**KayTools-2.0.0-RC1-win-x64-Setup.exe**](https://github.com/IvanBorisovich/KayTools-Releases/releases/download/preview-2.0.0-rc.1/KayTools-2.0.0-RC1-win-x64-Setup.exe) и запустите **внутри Windows**. Установщик включает необходимую среду .NET; Visual Studio не требуется.

[Описание Preview-релиза](https://github.com/IvanBorisovich/KayTools-Releases/releases/tag/preview-2.0.0-rc.1). У установщика пока нет сертификата Authenticode; криптографическая подпись каталога обновлений — отдельный механизм.
В каталоге выберите нужное приложение и нажмите «Установить». Скачивание, проверка и установка выполняются внутри оболочки. После завершения появится «Запустить».

На рабочем столе нужен только ярлык KayTools. После запуска приложения оболочка сворачивается в область уведомлений. Если GitHub недоступен, ранее установленные приложения остаются доступны.

## Структура хранилища

| Раздел | Содержимое |
|---|---|
| `catalog/` | Подписанный `preview.json`; `stable.json` появится после отдельного утверждения стабильного выпуска |
| `apps/` | Описание продуктов и их идентификаторы |
