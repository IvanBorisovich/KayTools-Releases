# Безопасность обновлений

- Читать и скачивать опубликованные пакеты может любой человек. Публикация и изменение репозитория доступны только уполномоченным участникам.
- KayTools проверяет подпись каталога и контрольные суммы программных файлов.
- Каталог публикуется после загрузки всех пакетов. Выпуск исправления получает новый номер версии.
- Рекомендуется включить неизменяемые релизы (immutable releases) и двухфакторную защиту учётных записей издателей.
- Обновление работающего приложения откладывается. Пользовательские документы и резервные копии не входят в обновление.
- Закрытые ключи подписи не распространяются с программой. GitHub-токен пользователю не нужен.
- Недоступность GitHub не должна запрещать запуск уже установленной версии.

Подпись каталога не является подписью Windows Authenticode и не обещает отсутствие предупреждений SmartScreen. Абсолютная защита от компрометации компьютера или ключей издателя не гарантируется.
